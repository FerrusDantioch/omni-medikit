Mise à jour

Omni-MediKit fonctionne hors ligne grâce à une copie enregistrée sur l'appareil. Touche « Mettre à jour » pour chercher une nouvelle version et l'appliquer tout de suite — tes données restent telles quelles, rien ne change sans ton accord.

Apparence

Choisis le thème de l'application. Le choix est mémorisé localement et s'applique immédiatement, sans recharger.

Taille du texte :

Données

Toutes les données (profils, traitements, prises, vaccins, contacts, constantes, réglages) sont stockées uniquement sur cet appareil, dans IndexedDB. Exporte-les en JSON pour une sauvegarde manuelle, ou réimporte une sauvegarde (chaque enregistrement est validé avant). Tu peux aussi ouvrir un fichier .json directement depuis le gestionnaire de fichiers de l’appareil, ou transférer les données vers un autre appareil par QR code.

Snapshots automatiques

Un snapshot des données est enregistré automatiquement chaque jour (et avant chaque import ou suppression), les 5 plus récents sont conservés.

Rappels de prises

Active les rappels pour recevoir une notification à l'heure de rappel de chaque traitement (champ « Heure de rappel » du formulaire). L'autorisation du navigateur est demandée à l'activation ; les rappels fonctionnent quand l'application est ouverte ou récemment en arrière-plan.

Verrouillage

Optionnel : protège l'ouverture d'Omni-MediKit sur cet appareil par un code à 4 chiffres. Les données restent stockées localement ; le code bloque seulement l'accès à l'application.

À propos d'Omni-MediKit

Omni-MediKit est une application de suivi de traitement médical, PWA fonctionnant à 100 % hors ligne et installable sur tablette et smartphone. Aucun backend, aucun serveur : toutes les données restent localement sur l'appareil.
