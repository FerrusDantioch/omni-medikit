Apparence

Choisissez le thème de l'application. Le choix est mémorisé localement et s'applique immédiatement, sans recharger.

Données

Toutes les données (profils, traitements, prises, vaccins, contacts, réglages) sont stockées uniquement sur cet appareil, dans IndexedDB. Exportez-les en JSON pour une sauvegarde manuelle, ou réimportez une sauvegarde.

À propos d'Omni-MediKit

Omni-MediKit est une application de suivi de traitement médical, PWA fonctionnant à 100 % hors ligne et installable sur tablette et smartphone. Aucun backend, aucun serveur : toutes les données restent localement sur l'appareil.
